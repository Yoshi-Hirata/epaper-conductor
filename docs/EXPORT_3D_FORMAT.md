# 3D シミュレーター向け書き出し形式 `epaper-3d-timeline` v1

Conductor の Timeline にある **Export for 3D simulator…** が書き出す JSON の仕様。
3D シミュレーター側(Blender など)はこのファイルだけで、ショー全体の
**すべての鱗の色の変化を、書き換え中のちらつきも含めて** 再現できる。

- 中身は**結果だけ**(いつ、どの鱗が、何色になるか)。遷移の順番や遅延を
  決める計算規則は含まれず、受け取り側で計算する必要もない。
- 補間は **constant**(次のキーまで色を保持)。キーの間を補間しないこと。
- Conductor の Timeline のプレビューと同じ絵になる(50 ms 刻みで全鱗を照合する
  テストあり: `tests/test_export3d.py`)。

## 取り決め:鱗の名前

鱗は配線ファイル `*_map.csv` の `label`(例 `017-01` = 基板 17・ソケット 1)で
識別する。**3D モデルの鱗オブジェクトにこの名前を付けておくこと**が、受け取り側に
求める唯一の取り決め。各鱗の `side`(front / back)・`row`・`col` も参考として
付けてあるので、名前付けの照合に使える。

## 全体

```json
{
  "format": "epaper-3d-timeline",
  "version": 1,
  "exported": "2026-10-14T12:00:00",
  "duration": 654.0,
  "music": {"name": "27SS_10m25s_v3.mp3"},
  "interpolation": "constant",
  "colors": ["#2b2a4e", "#3a2f5a", "..."],
  "palette": [{"code": 0, "name": "White", "hex": "#89adc3"}, "..."],
  "items": { "<item>": { "...": "下記" } }
}
```

| キー | 意味 |
|---|---|
| `duration` | ショーの長さ(秒) |
| `music.name` | ショーの音源のファイル名(音声データそのものは別途受け渡し) |
| `colors` | キーが参照する色の表。`"#rrggbb"` |
| `palette` | デザインに使う 16 色(参考。キーは `colors` を引けば足りる) |
| `items` | 衣装・バッグごとのデータ。キーは品番(例 `AZ271SD1305`) |

## `items.<item>`

```json
{
  "look": "23",
  "model": "AZ271SD1305",
  "scales": [{"label": "017-01", "side": "front", "row": 1, "col": 11}, "..."],
  "cues": [{"id": "16", "design": "AZ271SD1305_2_HW.csv", "label": "2",
            "at": 120.0, "partial": false}],
  "keys": {"017-01": [[-7.865, 0], [-7.615, 1], "..."]}
}
```

| キー | 意味 |
|---|---|
| `scales` | その品番の全鱗 |
| `cues` | デザインが変わる指示の一覧(参考情報。タイムライン表示や字幕に使える)。遷移の種類や所要時間は含まない |
| `cues[].at` | その指示の時刻(秒)。`partial` は一部の鱗だけを上書きするデザイン |
| `keys.<label>` | その鱗の色の変化。`[時刻(秒), colors の番号]` を時刻順に並べたもの |

- 時刻はショーの時計(0 = START)で、ミリ秒単位。各鱗のキーの時刻は必ず増加順で、同じ時刻は2つない。開始前から表示しておく
  デザイン(プリセット)は**負の時刻**から始まる。
- 色番号が `null` のときは「ショーの色が付いていない状態」(開始前と同じ)。
  最初のキーより前も同じ扱い。受け取り側で決めた既定の見た目にする。
- 書き換え中の鱗は、暗転 → 色のにじみ → 目標色に近づく、の段階を
  0.25 秒程度の刻みで変化する。これもすべてキーとして入っている。

## 取り込みの例(Blender の考え方)

1. `items.<item>.keys` の各ラベルについて、同じ名前の鱗オブジェクトを探す。
2. 各キー `[t, c]` で、フレーム `round((t + オフセット) × fps)` にマテリアルの色
   `colors[c]` をキーフレームとして打つ。補間は **Constant** にする。
3. `null` のキーは、既定のマテリアル色に戻すキーにする。
4. 音源 `music.name` を時刻 0 に合わせて置く。プリセットの負の時刻を見せたい場合は、
   オフセットをその分ずらす。

この手順をそのまま実装したスクリプトが **`tools/blender/import_epaper_3d.py`** にある
(Blender 3.6〜5.x)。色はオブジェクトの色(`obj.color`)に Constant で打つので、
ビューポートは Solid の Color: Object ですぐ見え、レンダーは同梱のマテリアル
「EPaper Scale」(Object Info → Color)で出る。

## 大きさの目安

フルのショー(52 指示・約 8,000 鱗)で約 16 MB、書き出しに 10 秒前後かかる。
