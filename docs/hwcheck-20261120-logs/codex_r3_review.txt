## Findings

1. **Major — A delayed kick can undo STOP, HOLD, or SEEK.** `conductor/fleet.py:2175–2184`, `ui/agent.py:473–504,528–543`. A kick can pass its generation check, spend time connecting, and reach the garment after a newer command. With no beacon heard this boot, the agent dispatches the old START unconditionally. If it heard a different Conductor’s beacon, `_late()` still declines to order this serial. A late kick can restart a stopped or held garment, restore an old T0 after SEEK, or cancel a pending clear after STOP (`ui/showplay.py:635,786–801`). The default timeout is **3 seconds per socket operation**, from twice the 1.5-second poll timeout (`conductor/fleet.py:53,219,317–340`). There is no end-to-end command expiry. Even with a matching beacon, the unit must have seen a newer generation to drop the kick. **Smallest fix:** remove the kick. To retain it, require receiver-side generation ordering for kicks over HTTP with the beacon off, plus a receiver-enforced expiry independent of T0. A shorter sender timeout alone leaves the race open.

2. **Major — M3 still fails when a second toggle lands during the retry.** `conductor/fleet.py:2065–2104,2234–2239`. Start with the switch OFF. Publish ON during the first admission, so START retries and decides to omit a garment. Publish OFF during the retry. That OFF returns success, but START commits the ON decision because the revision check is limited to `attempt == 0`. The retry rebuilds `silent`, `skip`, `left_why`, `targets`, and `forced_units` from the original inputs, so it does use its own targets. The lock is balanced on ordinary return and exception paths, and the loop is bounded to two decisions. However, `_waved` is published before the revision check and can survive an abandoned attempt if the retry refuses. **Smallest fix:** check the revision on both attempts and refuse with a retry message if it changes again. Use a `with` block for the commit lock and publish `_waved` only after admission passes.

3. **Minor — Kick workers are unbounded across STARTs, and their replies can update fleet state.** `conductor/fleet.py:2169–2191,317–340`. Repeated forced STARTs with a reply-losing garment can leave multiple workers in flight for the same unit. `_silent_kicks` is overwritten and provides no cap. `offset` uses the link lock and T0 uses `_run_lock`, but `shows` is read outside that lock, so a rescue upload can change the show mapping independently of the kick’s run generation. A successful reply also goes through `_learn` and can publish status and reachability. The POST exceptions are swallowed, but an exception before the `try` escapes the worker, and a `Thread.start()` failure can escape START after the run has committed. **Smallest fix if retaining kicks:** cap them at one in-flight operation per unit, capture the admitted show ID, pass `learn=False`, and contain worker and launch failures.

4. **Minor — The preview can promise a START or a rejoin that the actual command refuses.** `conductor/fleet.py:2314–2337,2344–2358`, `conductor/server.py:4187–4198,4428–4447`, `conductor/web/index.html:6287–6302`. A timeline edit can trigger `_one_timeline()` while the preview still says START will go without a named garment. A garment that comes back with cleared pictures cannot join merely by answering. With the beacon off, it may already be playing from the kick. When every target is silent, `_silent_verdict()` returns no reason and the panel is blank unless the preset branch supplies one. The hint follows the remembered START position, while the endpoint also accepts an explicit `from_s`. **Smallest fix:** describe the preview as the silence rule’s result, qualify rejoining on readiness, and supply an all-silent reason. Per poll, OFF takes the run lock and returns without a link scan. Eligible ON scans the targets with one locked observation each and sorts the silent names. If a target is silent and the remembered position is zero, the server also reads and parses `show.json` under the workspace lock (`conductor/server.py:666–668,1187–1189`). Poll latency is **not verified**.
